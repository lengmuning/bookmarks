Safari Bookmarks Sync

This extension now uses sync v2. Pair it again with a new code from the Mac app.

Bookmarks that Safari also has are moved into “Other Bookmarks › Safari Bookmarks”, following Safari’s folders, and duplicates are removed. An existing “Safari Bookmarks” folder is renamed and kept for you to review. A backup of all your bookmarks is saved first.
